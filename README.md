# Dynamic Modeling and Equilibrium Analysis of a Quadruple Inverted Pendulum

四级倒立摆动力学建模与平衡分析（Pendulum Lab / 多重自由摆实验室）。项目同时保留 1～5 重摆的建模、控制、验证与交互实验功能。

完整需求沿革、双方对话原文、求解器实现及验收记录见 [项目日志](项目日志.md)、[对话归档](docs/history/对话原文.md) 和 [求解器详解](docs/求解器与实现详解.md)。

当前分享版本为 `dist/倒立摆实验室_完整便携包_20261113` 下的 **网页版.zip / 桌面版.zip**，两版均自带运行环境与完整求解器。网页版解压后双击“打开网页版.exe”，自动查找实际浏览器；桌面版双击“倒立摆.exe”，自带引擎，不依赖系统 Edge。交付快照含前四阶 310 条加五阶 574 条方向；五阶完整 992 条仍在续算。旧单 HTML 为受限历史展示版。成品与运行库不纳入源码 Git，构建/摘要和测试说明见 [完整分发说明](docs/portable-share.md)。

下文保留源码运行方式及各阶段实验说明；历史 57 个下垂目标与全起止转换、计算库累计进度与便携包已激活快照采用不同统计口径，当前状态以项目日志的带时间快照为准。

## 启动

双击 `启动实验室.cmd`，或在 PowerShell 中运行：

```powershell
# 先进入下载或克隆得到的项目目录
python launch.py
```

打开 http://127.0.0.1:8765/ 。直接双击 `web/index.html` 不能启动本机求解服务；项目根目录 `index.html` 提供启动说明与入口。

需要 Python 3.11 或以上。新环境安装：`python -m pip install -r requirements.txt`。运行浏览器 Worker 的自动化测试还需要 Node.js。依赖安装完成后，本机实验室不依赖在线服务；仓库不包含本机的 `.vendor` 依赖副本。

## 操作

当前界面切换起点或终点后会自动起摆，稳定保持 10 秒后循环。用“序列演示”连续转换全部组合；支持 0.1×～10× 连续调速及手动输入，用“停止摆动 / 继续摆动”控制仿真时钟。演化时间轴终点为进入稳态后 0.5 秒，拖动时通过真实动力学重新积分到指定时刻。

“录制核心区”只录制摆体、关键数值和六组曲线，排除浏览器及操作栏。输出最高 1080p、目标 30 帧/秒的 WebM，同时保存在项目 `recordings` 文件夹，并提供“保存录制文件”入口。录制不采集麦克风或其他窗口。摆杆和关节始终绘制在小车前方。

- 默认 3 重，所有杆完全下垂、角速度为零；可切换 1～5 重。
- 1～4 阶可选包含全下垂的全部 `2^N` 种目标；5 阶开放除全下垂外的 `2^N-1` 种目标。共 57 个完全下垂起摆任务，全部路径可从“路径仓库”选择初态与目标播放。
- 默认参数下的 **57 项现已全部通过验收**。路径仓库可按初值卡片选择目标回放。
- 1～4 阶切换起点或终点后立即执行对应转换；5 阶的“悬垂起摆”直接加载 `precomputed_swingups` 中已验收的离线控制文件，并立即开始非线性积分。没有就绪方案或修改过物理参数时，保持下垂并明确显示原因。
- “路径仓库”：选择带角度和角速度的初始姿态卡片，再选目标，点击“开始演示”回放已有路径。没有已存解的组合会启动求解。
- 仓库中的“手动输入初值”：输入小车位置/速度、每根杆角度/角速度和目标。成功后自动入库。
- 自定义初态和失衡恢复会优先使用“消能回中 + 已验证轨迹接入”，通过完整积分验收后执行；不重置真实摆角。已验证 146 组含随机角速度的初态，146 组也均通过真实页面 Worker 复验，详见 `docs/recovery.md`。
- 三重摆支持含基态的全部 8 种上下组合平衡目标，任意两个不同姿态之间均有直接转场，共 56 条。含向上杆的姿态依靠闭环维持，并非开环自然稳定。
- 1/2/3 阶分别 2/12/56 条有向转场，合计 **70/70 已预优化并验收**。选择起止姿态后立即跳到起点执行；“转场矩阵”一键切换。“序列演示”从所选起点开始，各段连续衔接。详见 `docs/equilibrium-transfers.md`。
- 四级已开放 16×16 转场矩阵。当前随仓库发布的 240 条有向路径全部为已验收的直达解，包含完全下垂基态；对应索引的完整连续巡游也已通过验收。验收证据见 `results/fourth-order-acceptance.json` 和 `results/fourth-order-worker-audit.json`，批处理方法见 `docs/fourth-order-cluster.md`。四级入口：http://127.0.0.1:8765/?order=4 。
- 起点和终点改为始终展开的箭头按钮；从左到右对应各杆，颜色与画布一致，包含完全下垂基态。四阶较难组合支持经明确中间姿态连续衔接的已验收轨迹，界面与直达解分开标明；后台继续用新直达解替换较长的衔接路径。
- 主画面提供连续转角、角速度、小车位移、小车速度、推力、机械能六组动态图表；12/30/60 秒窗口、同步游标，绘制与物理线程解耦。物理参数和系统分析统一放在“参数与分析”。
- 成功轨迹支持时间轴拖动、停止摆动、单步和 0.1～10 倍无级调速，也可手动输入倍率。1～5 重完全下垂起摆的真实成功记录可直接演示。
- 点击轨道移动位置目标，左右箭头或按钮施加 0.12 秒的顶端外力；Space 暂停，R 随机初态。
- 部分观测实验限于全直立附近；混合目标使用全状态反馈。

## 物理与求解

所有杆都是可自由转动的均匀刚性杆，关节只有被动阻尼，无电机或控制转矩。唯一执行器为小车水平力，默认上限 120N，轨道范围 ±2.4m。按质量矩阵处理端点冲量；不通过修改摆角稳定对象。
模型、坐标、限位及外部扰动的推导见 `docs/model_derivation.md`。

对象为真实非线性模型，默认 RK4 固定 1ms、控制/观测 250Hz；可选 0.5ms，此时控制更新为 500Hz。Worker 与渲染解耦，以最高约 125Hz 推送物理状态，Canvas 自动跟随且保留轨道缩略图。
控制为受限 Hermite–Simpson 轨迹优化 + TVLQR，落稳后使用对应目标的 CARE LQR。规划/独立验证时显式暂停仿真时钟。
完全下垂预优化文件绑定精确参数与初值，并保存文件摘要和离线验收结果，运行时只查表。自定义初值的反馈方案允许角度绕回、有限偏差及镜像，复用前独立重放验证；新的自定义组合使用多次搜索。有限推力/轨道不保证任意初值全局成功，也未宣称最短时间最优。

默认完全下垂至全直立验证：1～5 重约 3、4、5、6、7 秒进入落稳阶段；五重峰值力约 82.7N，最大小车位移约 1.974m。数据见 `results/acceptance.json`。这些结论不延伸到任意初值或任意混合目标。

RK4 与 DOP853（rtol 1e-11、atol 1e-13）1 秒对照的最大状态差约 6.7e-11；保守系统 3 秒能量误差约 6.4e-11J，见 `results/accuracy.json`。不宣称长期严格守能。

## 验证与批处理

```powershell
python -m pytest -q
python -m triple_pendulum.audit
python -m triple_pendulum.cli run --order 3 --duration 12
python -m triple_pendulum.cli run --order 3 --duration 1 --reference
python -m triple_pendulum.cli benchmark --orders 1,2,3,4,5 --duration 12
python -m triple_pendulum.precompute_all --workers 2 --rounds 4
python -m triple_pendulum.precompute_equilibria --workers 3 --rounds 3
python -m triple_pendulum.precompute_transitions --orders 5 --workers 2
python -m triple_pendulum.precompute_refine --order 5
python -m triple_pendulum.recovery_audit --workers 2
python -m triple_pendulum.recovery_audit --workers 2 --stress
```

测试包括质量矩阵、独立拉格朗日核对、能量、线性化、单小车执行器、7 个目标的闭环极点、观测器、1～5 重非线性收敛、Python/浏览器动力学一致性、陈旧任务取消、轨迹仓库和回放。
新增检查涵盖全部 57 种目标的 LQR 极点、预计算文件的直接装载，以及真实 Worker 在完全下垂起摆时不发送任何在线优化请求。局部极点检验与完整起摆验收分别执行；进度表中的 `ready` 表示完整起摆验收通过。
当前 57/57 均为 `ready`，全部经过 1ms RK4 独立物理回放和真实页面 Worker 复验，未触碰轨道端点、未超过推力上限、未调用在线规划。约 3～19 秒进入稳定，全部方案中的最大小车位移约 2.102m、峰值力 120N；汇总见 `results/precomputed-acceptance.json`。该结论仅覆盖默认参数、完全下垂静止初值。
最大矩阵维度测试到 10 重；GUI 只开放 1～5 重。没有把 6～7 重标为已实现。
离线搜索可复用已验证的起摆路径并追加姿态转换，也会逐级细化已保存候选网格；最终都重新从下垂静止做完整物理回放。信号图使用连续转角保留转圈次数，画布角度标注使用主值角。

## 限制

部分极端初值的受限起摆仍可能找不到可验证解；仓库逐条标明已有解，近目标记录不冒充下垂起摆。没有实现完整的测量延迟/丢包、模型失配面板、执行器滞后或所有原始提示词中的扩展功能。
轨迹仓库为本地文件，浏览器最近成功还保存在 IndexedDB。清理浏览器存储不会删除 `trajectory_repository` 中的服务器记录。
