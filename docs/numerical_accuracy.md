# 数值精度与实时调度

非线性对象采用 float64、RK4，默认固定步长 0.001 秒，可改为 0.0005 秒。
Web Worker 根据墙钟累加仿真时间，分批推进固定步长。达不到实时速度时保留时间债务，显示落后量，不增大步长或丢弃物理步骤。
暂停、页面后台、起摆规划期间仿真时钟暂停。控制/观测每 4 个物理步更新，零阶保持输入。
绘图使用 requestAnimationFrame，显示帧率取实际回调计数。物理与渲染在线程上隔离。
页面掉帧不修改物理步长。0.5ms 模式的控制/观测频率为 500Hz。

Python 参考积分器采用 DOP853，rtol=1e-11，atol=1e-13，在物理/采样边界分段积分。
测试从同一小角度初值运行 1 秒，RK4 和 DOP853 真值轨迹最大允许绝对差 2e-7，另加相对容差 1e-6。
具体实测误差保存于 results/accuracy.json。
保守无阻尼、无输入的 3 秒 DOP853 能量误差要求 <2e-8 J；不声称 RK4 或 DOP853 长期严格守能。

触壁包含离散冲量事件，不应用平滑 ODE 误差阈值跨越该事件。
规划配点残差不等同于连续轨迹误差，因此必须独立闭环重放验收。

CLI 基准是无绘图的 CPU 仿真速度，不代表浏览器 FPS；浏览器 FPS 是界面实测。
计时包含动态分配及 Python/Numba 边界开销。首次 Numba 编译可能进入首次基准耗时。
目前最大矩阵维度测试到 N=10，GUI 和闭环稳定测试仅 N=1～5；不能据此声称 N=10 实时起摆成功。
