# 控制、起摆和观测

## 局部稳定

CARE 求解 LQR：u=−K(s_hat−s_ref)，Q 按位置、杆角、线速度和角速度生成，R>0。
执行力始终饱和；没有积分项，anti-windup 不适用。本版本没有执行器滞后和力变化率限制。
有限力和轨道意味着 LQR 仅在局部有效。GUI 中“已稳定”需要角误差 <0.5°、所有杆角速度 <0.03 rad/s、位置误差 <0.03m 持续至少 1 秒。
最大角度、饱和率、触壁数和连续稳定时间都来自真实积分状态。

## 完全下垂起摆

初值为 x=0、所有 θ_i=π、所有速度=0。轨迹优化的终点取最近的 2π 整数倍直立点。
采用 Hermite–Simpson 配点，将真实非线性动力学作为约束，控制变量只有标量小车力。
随后沿轨迹线性化，反向解有限时域 Riccati 递推，形成 TVLQR 反馈。
物理状态始终通过 RHS/RK4 推进；参考状态只供反馈计算和误差比较，不写入物理状态。
三次 Hermite 插值用于参考，而非真实状态。默认规划仅使用 66% 推力，剩余推力供反馈纠偏。
规划不是严格的最短时间求解：时长为用户设置的固定预算，可在高级参数中调整。

候选轨迹在独立 RK4 闭环仿真中检查角误差、速度、小车行程，未通过的轨迹不执行。
失败会显示原因并稍后从当前状态重新规划。规划计算期间显式暂停仿真时钟，这不是毫秒级 NMPC。
模型相同、完全下垂时使用以前优化得到的解作为数值初始猜测，仍重新求解并验证；不会播放录制动画。
改变初值会改变边值问题，非凸求解可能失败。没有对任意初值全局成功的证明或声明。

## 观测与不可见

传感器选项：全状态；小车位置和各角度；小车位置及顶端水平位置；仅小车位置。
后两者不提供任何真实角度或角速度。控制器只使用观测器估计值。
测量接口与观测器接口隔离，真实状态仅在对象、传感器采样及显示/诊断层使用。
部分观测闭环的默认演示从近直立开始；不宣称线性观测器可以处理完全下垂的非线性起摆。

Luenberger 用固定增益修正线性模型预测；Kalman 根据过程和测量协方差调整增益；EKF 使用非线性模型和局部测量 Jacobian。
Kalman/EKF 协方差更新使用 Joseph 形式并对称化。JavaScript 线性预测使用一阶离散化，Python 使用矩阵指数；两者只有非线性对象/RK4 做逐项一致性测试。
默认传感噪声是零，GUI 可加独立高斯噪声，生成器固定种子。当前未实现测量延迟、丢包和量化。

可控性表示小车力是否能影响每个模态；可观性表示有限测量是否足够反推隐藏状态。
矩阵幂按最快开环极点幅值缩放后报告 SVD 秩、最小奇异值和条件数；不同缩放下条件数不同。
条件数 >1e9 时提示数值上接近不可观，不能把满秩当成鲁棒性保证。
