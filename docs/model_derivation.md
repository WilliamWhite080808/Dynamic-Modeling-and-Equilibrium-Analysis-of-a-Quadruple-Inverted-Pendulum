# 自由 N 重摆：坐标、动力学和边界

单位全部为 SI。小车坐标 x 向右为正，角 θ_i 为相对竖直向上的绝对角，向右倾为正。
每根杆均可连续旋转；没有角度限位、关节电机或人为保持直立的约束。小车是唯一执行器。
杆之间允许在二维投影中穿过，未模拟杆间碰撞。

第 i 根杆质心坐标：

    r_i = (x + Σ_{j<i} l_j sin θ_j + c_i sin θ_i,
           Σ_{j<i} l_j cos θ_j + c_i cos θ_i)

均匀刚性杆 c_i=l_i/2，I_i=m_i l_i²/12。端点质量模型则 c_i=l_i，I_i=0；两者通过参数分别组装。
默认质量与长度从基端到顶端略微递减，具体数组由接口返回，避免将几根等频杆的数值条件性混淆。

    T = M_cart xdot²/2 + Σ_i [m_i |J_i qdot|²/2 + I_i θdot_i²/2]
    V = g Σ_i a_i cos θ_i
    a_i = m_i c_i + l_i Σ_{k>i} m_k
    H_ii = m_i c_i² + I_i + l_i² Σ_{k>i}m_k
    H_ij = l_min(i,j) a_max(i,j), i≠j

势能零点选在各广义角同时水平时的总势能，直立时最大，悬垂时最小。质量矩阵维度为 (N+1)×(N+1)：

    M_00 = M_cart + Σ m_i
    M_0i = M_i0 = a_i cos θ_i
    M_ij = H_ij cos(θ_i − θ_j)

拉格朗日方程得到：

    b_0 = u − d_cart xdot + Σ a_i sin θ_i θdot_i²
    b_i = g a_i sin θ_i − Σ_j H_ij sin(θ_i−θ_j) θdot_j² − (Dω)_i
    M(q) qddot = b

D 是相对关节速度形成的被动阻尼矩阵：耗散功率
d_1 ω_1² + Σ_{i>1} d_i (ω_i−ω_{i−1})² ≥0。阻尼不执行任何起摆或稳摆命令。
程序解线性方程，不显式求逆。Python/Numba 与 JavaScript 为两份独立实现，测试核对 RHS 和 RK4 单步。

唯一控制力满足 τ_control=[u,0,…,0]。专项测试在任意非零姿态与速度下验证：

    M(q) [qddot(u) − qddot(0)] = [u,0,…,0]

在顶端按“推一下”施加水平外力 F 时，真实外扰广义力为
[F, F l_1 cos θ_1,…,F l_N cos θ_N]，只持续 0.12 秒。这是人为外界冲击，不是持续的关节执行器。

## 轨道端点

小车范围为 |x|≤rail。通常用软刹车提前制动。起摆规划在节点和中点约束小车位置，反馈跟踪保留推力余量。
起摆过程中不额外叠加软刹车，以免破坏已经考虑轨道的控制轨迹；硬限位始终启用。

发生端点接触时按无摩擦冲量更新广义速度（恢复系数 e=0.05）：

    Δqdot = M(q)^−1 e_x J
    J = −(1+e) xdot / (e_xᵀ M(q)^−1 e_x)

实际计算使用 solve。此处的速度变化来自轨道碰撞，角速度的同时变化是质量矩阵耦合造成的。
位置约束投影仅将发生穿透的小车放回端面，属于离散接触模型；没有投影摆角。

## 线性化

直立点 ω=0，sinθ≈θ。令 G_ii=g a_i（小车行列为零）：

    A = [[0, I], [solve(M0,G), −solve(M0,D)]]
    B = [[0], [solve(M0,e_x)]]

状态顺序始终为 [x,θ_1,…,θ_N,xdot,ω_1,…,ω_N]。测试以中心差分交叉核对 A、B。
质量矩阵还使用独立几何 Jacobian 装配交叉核对，非线性偏置使用 Christoffel 差分交叉核对。
