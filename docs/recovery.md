# 非下垂初态与失衡恢复

恢复过程仍然只有一个执行器：小车水平力。关节没有电机，也不在恢复阶段修改真实摆角、角速度或小车状态。

## 求解次序

1. 初值、目标和物理参数完全相同的已有成功记录直接复用。
2. 尝试直接非线性闭环捕获目标，或接入该目标已有轨迹的中间位置；通过独立积分后才使用。
3. 用小车力消能回中，在模拟得到的运动过程中搜索可接入已有起摆路径的状态。参考轨迹可以切换，真实对象的状态始终连续积分。
4. 没有找到通过验收的恢复路径时，才进入原有的受限轨迹优化。

恢复采用三组小车位置/速度反馈参数。无逃逸脉冲时，力为

\[
u=-0.4F\tanh\frac{k_x(x+0.5x^3/r^2)}{0.4F}
  -0.6F\tanh\frac{k_v\dot x}{0.6F}.
\]

它的绝对值不超过推力上限 \(F\)。给机械能加上小车回中势能，令势能导数等于上述回中力的相反数，则其时间导数为非正的小车阻尼和被动关节阻尼耗散项。该关系用模型机械能的独立数值微分做了核对。

若初态恰好静止在其他上下组合平衡姿态，会施加一个持续 0.6 秒、幅值 12N 的小车力脉冲打破静止。加上脉冲后的总力仍受上限约束。这不是关节力矩。

轨迹接入的思路与 [MIT Underactuated Robotics 的轨迹稳定反馈说明](https://underactuated.mit.edu/trajopt.html)相关。本项目使用独立非线性回放检验接入点，没有把样本测试写成全状态空间的数学证明。

## 独立验收

Python 从用户给定的完整初值重新做 1ms RK4 积分，控制更新为 250Hz。完整恢复与起摆过程均需保持轨道余量，落稳要求角度误差小于 0.5°、角速度小于 0.03rad/s、小车位置误差小于 0.03m，并连续保持至少 1 秒。

页面 Worker 再从相同初值执行同一个控制器，检查收敛、不触壁、不超推力和没有额外重规划。Python 与 JavaScript 的耗散力表达式有数值一致性检查。

当前测试：

- 96 组基础试验：全部 57 个目标、随机初态、轨道两侧初态、其他完全静止平衡姿态。
- 50 组更高角速度试验：角度在 ±π 内随机取值，初始角速度在 ±6rad/s 内取值，小车位置在 ±1.6m、速度在 ±1.5m/s 内取值。
- 146/146 通过独立积分，146/146 再通过真实页面 Worker。每条成功解已保存进初态仓库。

测试输入、目标和逐项结果分别保存在 `results/recovery-audit.json`、`results/recovery-stress-audit.json`；页面复验结果在 `results/recovery-worker-audit.json`。

## 扰动与记录

自动恢复会等待用户外力脉冲完整结束，再以受扰后的状态求解。新实验会清除旧实验的外力及其截止时刻。长时间实验的成功回放通过逐级降低采样频率保留最初一帧，不再丢掉原始初值。

当前实验条件为默认物理参数、全状态测量、无测量噪声；有限范围试验不是对无限角速度、不可行边界状态或任意模型失配的保证。
