# 1～3 阶全部稳态互转

所有角度从竖直向上计，U=0、D=π；角速度和小车速度的稳态值均为零。含全下垂基态，共 2、4、8 种姿态，任意两个不同姿态间的有向路径数为 2 + 12 + 56 = **70**。4～5 阶保留原有行为。

## 页面操作

- 主工具栏统一放置阶数、起点、终点和“播放转场”。手动点播直接载入所选起点，立即开始真实积分；允许中断正在播放的路径，不要求当前姿态与起点一致。
- “转场矩阵”每一行是起点，每一列是终点。点绿色按钮就会关闭矩阵、跳到起点并播放，不再只选中而不执行。
- 暂停或历史回放时也可点播。历史回放会自动退出，载入新路径的起始位置、摆角和速度。快速连续点击以最后一次请求为准。
- “巡游”先载入所选起点，再连续执行当前阶数的全部 2/12/56 条有向边；后续各段仍保持物理状态连续。再次点击会停止追加路径。
- 路径仓库保留初值卡片、角速度和回放进度。参数与系统分析收进统一设置窗口。
- 六组实时曲线为连续转角、角速度、小车位移、小车速度、驱动力和机械能。独立以约 60 Hz 渲染，支持 12/30/60 秒窗口、同步悬停读取和清空；清空图表不重置仿真。曲线显示真实采样，按像素抽样时保留极值，不改变物理数据。

## 物理与边界

仍使用原有均匀刚性杆、被动关节阻尼、非线性耦合质量矩阵。没有关节执行器，唯一输入为小车水平力。默认力上限 120 N、轨道 ±2.4 m；新增转场推力变化率限制为 500 N/s。1 ms RK4 积分与 250 Hz 控制运行在页面 Worker 中，转场过程中无需在线规划或暂停时钟。

70 条均为单条直接轨迹，无消能阶段或基态中转拼接。离线受限配点优化采用零初末推力，配合时变 LQR 跟踪和目标 LQR 保持。回基态可使用反向参考作为候选，但必须经过原方向的真实非线性物理积分验收。

## 验收

`equilibrium_transitions/status.json` 保存 70 条记录及参数、文件 SHA-256、独立物理验收结果。运行时按参数和实际起点校验后加载，修改物理参数不会冒用默认方案。

1. Python 从每个确切稳态独立做 1 ms 物理回放，全部 70 条通过；末尾连续稳定，角误差 <0.5°，角速度、小车速度 <0.03，位置误差 <0.03 m，轨道保留至少 4% 余量。
2. 使用页面实际 `sim-worker.js`，70 条逐一热切换验证，再按 1/2/3 阶欧拉回路串行执行全部 70 条。每次安装轨迹逐值断言状态、时钟、当前控制力、物理 epoch 不变；全部收敛，触壁和在线规划请求均为零。
3. 浏览器实际操作验证全上 → 全下 → 混合姿态、混合姿态直接互转，检查帧率、可见范围、矩阵、巡游与初态仓库。

数据见 `results/equilibrium-transfers-acceptance.json` 和 `results/equilibrium-worker-audit.json`。验证结论针对默认参数及稳态附近的转场入口；没有宣称最短时间最优或任意速度下的全局可控性。
