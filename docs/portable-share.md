# 分享入口

当前小于100MB的完整桌面分享实验在 `dist/实验/桌面版`。只发送这个完整文件夹，或它的标准ZIP；双击“倒立摆.exe”直接进入，无选择页、安装依赖、手动启动服务或命令步骤。

保留全部原功能和现场求解，651个独立双向插件、1302方向。新版运行库约39.57MB并自动展开至用户缓存；原生核代替收件人的Numba/LLVM环境，轨迹使用逐位无损修正。当前构建和实际验收见[说明](compact-desktop.md)，精确大小/SHA见results/acceptance/compact/final-report.json。

原dist/网页版、桌面版按用户本轮“先在实验目录构建、不损坏原文件”要求保持原状。它们的旧激活快照比计算库少，不能误判为数据丢失；也不能后台替换。已有应用新增动作仍由用户手动点击“检查轨迹更新”激活。

本项目不再生成受限的单HTML展示版。桌面内部的HTML/JS/CSS是实际WebView2/浏览器界面资源，不是第二个入口，不能删掉它们而保留界面功能。运行完整现场求解必须由EXE启动随包引擎，浏览器file权限不允许HTML自己启动本机进程。

历史分享说明保存在docs/history/分享交付沿革.md；历史日志不代表当前操作入口或当前验收数量。
