## 分享文件与启动

`dist/倒立摆实验室_轻量完整包_20261114/网页版.zip` 为 278,784,271 字节，桌面版 ZIP 为 279,028,860 字节，各约 279 MB（十进制）。分别解压后双击“打开网页版.exe”或“倒立摆.exe”，直接进入。桌面优先复用已有 WebView2，失败自动使用已有浏览器，不安装或下载组件。无需外部 Python、Node 或求解器。现代 Windows 10/11 x64 为目标；实际验收为当前 Windows 11，不能声称所有 Windows 版本均实测。没有可用浏览器或 WebView2 的机器会显示明确错误，免安装不等于凭空存在图形引擎。
