# 初态—目标—路径解仓库

这是本地数据仓库，通过页面右上角“初态仓库”访问，不依赖 GitHub 或在线服务。

- `index.json`：索引，记录初始状态、目标、阶数、验证类型、角速度、峰值力、稳定时间和路径文件 ID。
- `<id>.json`：实际积分记录 `frames`，包含时间、小车位置、绝对角、线速度、角速度和小车力，以及模型参数和分析矩阵。
- 含 `control_plan` 的条目额外保存优化参考、控制力和反馈增益，可用于下一次求解的初始猜测。
- `status=verified` 表示经过独立非线性闭环重放校验；`status=recorded` 表示从实时对象采集，记录末尾连续 1 秒满足稳定阈值。

三重摆目标用 U（向上）和 D（向下）表示，顺序为基端至顶端。提供 UUU、UUD、UDU、UDD、DUU、DUD、DDU，排除全下垂 DDD。
“7 种目标都有解”不表示任意初值都能到达每个目标。界面逐卡标出已有解与待求解组合。近目标扰动收敛与完全下垂起摆是不同实验，卡片数值和记录名称分别标识。

从页面手动输入初值、选择目标并启动实验。受限起摆路径通过独立校验后自动入库；近目标直接 LQR 收敛等实时成功实验也会自动保存真实记录。
回放只显示记录，不向实时对象写入状态；退出回放恢复暂停前的实时实验。

写入采用原子替换、线程锁和文件锁。相同参数、初值、目标的独立验证方案按指纹去重。实时记录单独保留来源。
